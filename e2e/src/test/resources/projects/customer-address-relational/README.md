# customer-address-relational

Quarkus 3.40.1 scaffold for the shared customer-address relational model.

The pom imports the Quarkus BOM. That BOM manages Kotlin 2.4.10 and Testcontainers 2.0.5. MapStruct 1.6.3 is pinned here because the BOM does not manage it. The generator writes Kotlin and Java sources into this project.
